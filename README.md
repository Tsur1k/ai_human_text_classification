# Детекция сгенерированного текста с помощью ИИ

## Постановка задачи

Задача состоит в определении происхождения текста: был ли он написан человеком
или сгенерирован искусственным интеллектом (ChatGPT, GPT-3/4, Gemini, Claude и
другие языковые модели). Задача бинарной классификации текстов на "человеческие"
и "AI-сгенерированные"

## Формат входных и выходных данных

### Входные данные:

Датасет AI_human_classification, используемый при обучении, имеет следующую
структуру: всего имеется 390000 объектов (0.37 - рседнее значение таргета) для
тренировки и 20000 для теста

### Выходные данные:

Модель предсказывает вероятность сгенерированного ИИ текста

## Метрики

В задаче используются метрики F1, ROC-AUC

## Валидация

Поскольку в исходном датасете есть только train и test части, “возьмем” от
train-а 10% объектов. Во время валидации мы смотрим как падает loss и растут
метрики. Для визуализации используется логирование в mlflow.
