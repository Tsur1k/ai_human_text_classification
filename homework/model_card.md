# Model Card: Детектор AI-сгенерированного текста

## 1. Общая информация
- **Название модели**: AI Human Text Classification Model
- **Версия**: 0.1.0
- **Дата обновления**: Декабрь 2025
- **Автор**: Владислав Цуркан
- **Тип задачи**: Бинарная классификация текста
- **Фреймворк**: PyTorch Lightning, scikit-learn
- **Управление зависимостями**: Poetry, pre-commit, Ruff
- **Лицензия**: MIT

## 2. Предполагаемое использование
- **Прямое назначение**: Оценка вероятности того, что предоставленный текстовый фрагмент был сгенерирован языковой моделью (ChatGPT, GPT-3/4, Gemini, Claude и др.), а не человеком.
- **Downstream-задачи**: Модерация пользовательского контента, проверка академической честности, фильтрация ботов и спама.
- **За пределами области применения (Out-of-scope)**:
  - Определение конкретной языковой модели, сгенерировавшей текст.
  - Классификация нетекстовых данных (код, аудио, изображения).
  - Использование предсказания модели как единственного основания для серьезных административных или юридических решений без участия человека (human-in-the-loop).

## 3. Данные
- **Набор данных**: `AI_human_classification`
- **Объем**: 390 000 объектов для обучения, 20 000 объектов для независимого теста.
- **Распределение классов**: Доля положительного класса (AI-текст) в обучающей выборке составляет ~0.37 (37%), что указывает на умеренный дисбаланс классов.
- **Предобработка**: Токенизация, очистка и нормализация текста с использованием библиотеки NLTK.
- **Версионирование данных**: DVC (с удаленным хранилищем), что гарантирует воспроизводимость экспериментов.

## 4. Метрики и оценка
- **Основные метрики**: F1-score (учитывает дисбаланс классов), ROC-AUC.
- **Стратегия валидации**: Выделение 10% объектов из обучающей выборки в качестве валидационного набора (hold-out).
- **Мониторинг обучения**: Логирование потерь (loss) и метрик в реальном времени с помощью MLflow.
- **Управление конфигурацией**: Hydra (для гибкого управления гиперпараметрами без хардкода).

## 5. Этические соображения и ограничения
- **Смещения (Bias)**: Модель может быть предвзята к определенным стилям письма. Например, слишком формальный, шаблонный или, наоборот, очень простой язык может быть ошибочно классифицирован как AI-генерация.
- **Адаптация к новым моделям**: По мере обновления генеративных моделей их тексты становятся более "человечными". Эффективность детектора может снижаться (concept drift), что требует регулярного переобучения на свежих данных.
- **Конфиденциальность**: Модель не сохраняет и не передает входные тексты третьим лицам после этапа инференса (при соблюдении корпоративных политик развертывания).
